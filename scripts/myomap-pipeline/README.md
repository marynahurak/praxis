# Конвеєр анатомії для атласу міотестингу

Запис методу, яким згенеровано анатомічні зображення та геометрію для сторінки
«Атлас локалізації міоточок та конфігурації sEMG-електродів» (`src/views/MyoMap.astro`). Сайт під час збирання
ці скрипти **не запускає**: їхній результат уже лежить у `public/myomap/*.webp` і
`src/data/myomap-geo/*.json`.

## Джерело

BodyParts3D 4.0 © The Database Center for Life Science (DBCLS), ліцензія CC BY 4.0
(Mitsuhashi et al., 2009, doi:10.1093/nar/gkn613), у підготовці Human Atlas та Dagno —
npm-пакет `@dagno/anatomy-model`. Координати моделі: метри, вісь Y угору, +z — передня
поверхня, права сторона тіла має від'ємні x, анатомічне положення.

## Кроки

1. `extract.py` — декодує бінарні фрагменти моделі (float32 координати, uint32 індекси) і
   відбирає структури правої верхньої кінцівки та плечового поясу → `upper.pkl`.
2. Ручні кроки (виконано інтерактивно, тут описано для відтворюваності):
   додано шкіру й тримач м'язів-згиначів; додано грудну клітку як контекст для проєкцій
   плечового поясу; вилучено артерії та вени; вилучено сітку «Right flexor pollicis brevis»,
   яка в джерелі розташована на лівому боці (помилкова мітка) → `upper3.pkl`; сітки
   експортовано в `meshes.json` (base64) для браузера.
3. `render.html` + `render.cjs` — ортографічна візуалізація three.js у безголовому Chromium
   для кожної проєкції з `views.json` у чотирьох режимах: `shade` (затінення), `id`
   (кольорова мітка структури), `skin` (силует шкіри), `tendon` (сухожилкові зони).
4. `thickness.py` — сухожилкові зони за геометрією: кожну сітку м'яза розрізають 48 площинами
   перпендикулярно до її довгої осі; ділянка вважається сухожилковою, якщо площа перерізу
   менша за 16% від максимальної або товщина (2·площа/периметр) менша за 36% від
   максимальної. На поперечних зрізах (`section.py`) пороги — 12% і 30%. Це геометричне
   наближення, а не гістологічна межа м'язово-сухожилкового переходу.
5. `process.py` — маски → SVG-контури, рекомендоване місце (максимум перетворення
   відстаней у черевці без сухожилкових зон), довга вісь черевця (метод головних компонент),
   площі.
6. `lat.py`, `fix_lat.py` — схематичний контур найширшого м'яза спини (у моделі його немає).
7. `section.py`, `fix_sections.py` — справжні поперечні зрізи сіток на заданих рівнях; на
   рівні кисті позамізові м'язи передпліччя позначено як сухожилки.

Python: numpy, trimesh, shapely, opencv-python, scikit-image, scipy, Pillow. Node: playwright, three.
Шляхи до вхідних файлів у деяких скриптах відносні до робочої теки; перед запуском їх варто
перевірити.

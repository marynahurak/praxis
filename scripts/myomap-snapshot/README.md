# PDF-зріз атласу для Zenodo

Скрипти, якими з даних сайту збирається технічна записка «Атлас локалізації міоточок та конфігурації
sEMG-електродів» (українською та англійською) для депонування в Zenodo з DOI. Сайт під час збирання
їх не запускає.

Для нової версії атласу:

1. Оновіть `meta` і `changelog` у `src/data/myomap.json` (див. `docs/editing-guide.md`).
2. У Zenodo на записі натисніть «New version» і зарезервуйте DOI цієї версії («Get a DOI now!»).
3. Запустіть із кореня репозиторію (після `npm install`):
   `MYOMAP_DOI=10.5281/zenodo.NNNNNNN scripts/myomap-snapshot/make.sh`
4. Завантажте обидва PDF із `scripts/myomap-snapshot/build/out/` у чернетку Zenodo, оновіть поле «Version» і опублікуйте.
   Перевірте ліцензію в метаданих: CC BY-NC-ND 4.0 (за замовчуванням Zenodo пропонує CC BY 4.0).
5. Додайте DOI версії в `meta.doi.versions` у `src/data/myomap.json`.

Що робить збирання: растрові шари проєкцій (затінення + м'язи за роллю, змішування multiply) готуються
заздалегідь (`raster.cjs`), бо Chromium розтеризує змішування у PDF фрагментами; решта — вектор.
Зміст має два проходи: другий вписує номери сторінок, узяті із закладок першого PDF.

Тексти документа, яких немає на сайті (анотація, метод, правила оцінки), — у словнику `T` у `build.py`;
решта береться з `src/lib/myomap.ts` і `src/data/myomap.json` без змін. Правила оцінки в `build.py`
описують код `src/scripts/myomap-client.ts` — змінюючи код, оновіть і їх.
